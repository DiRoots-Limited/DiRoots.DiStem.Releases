Autodesk Revit 用の DiStem パッケージには、生産性を向上させる複数の Revit アドインが含まれています。BIM モデルデータの管理（要素のプロパティとパラメータの抽出およびマッピング）、Revit モデルのクリーンアップ、改訂雲マークの削除、データ転送、2D／3D ビューでの距離測定、要素座標の取得、glTF へのエクスポートを支援します。

### DiStem パッケージに含まれる機能
- Properties Extraction Mapping は、モデル要素から非表示のパラメータとプロパティ（例：位置 – X、Y、Z 座標）をすばやく抽出し、既存または新規の共有インスタンスパラメータに挿入します。
- Model Cleanup は、Revit モデルからビュー、集計表、シート、ビューテンプレート、フィルタ、リンク、読み込みデータ、画像を一括削除します。削除する要素を選択し、ワンクリックですべて削除できます。
- Revision Clouds Remover は、Autodesk Revit モデルから改訂雲マークを一括削除します。
- 2D & 3D Measure は、2D および 3D ビューで測定できます（2 点間の距離、エッジの長さ、1 点の座標）。
- glTF Exporter は、Autodesk Revit モデルを glTF ファイル形式にすばやくエクスポートします。
- CAD Manager は、Revit モデル内の CAD レイヤーを表示／非表示にし、色分けします。
- Project Standards は、複数の要素（例：ビュー、シート、ビューテンプレート、ドア、窓）を 1 つのプロジェクトから複数のプロジェクトへ一括転送します。
- StyleSync は、不要、未使用、重複しているスタイルをすばやく整理または統合します。線種、線パターン、塗り潰し領域、塗り潰しパターン、寸法、文字スタイル、マテリアル、ファミリに対応します。
- その他のツールも近日公開予定です。
