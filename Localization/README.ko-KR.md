Autodesk Revit용 DiStem 패키지에는 생산성을 높여 주는 여러 Revit 애드인이 포함되어 있습니다. BIM 모델 데이터 관리(요소 속성 및 매개변수 추출과 매핑), Revit 모델 정리, 리비전 구름 제거, 데이터 전송, 2D 및 3D 뷰에서 거리 측정, 요소 좌표 확인, glTF 내보내기를 지원합니다.

### DiStem 패키지에 포함된 기능
- Properties Extraction Mapping은 모델 요소에서 숨겨진 매개변수와 속성(예: 위치 – X, Y, Z 좌표)을 빠르게 추출하여 기존 또는 새 공유 인스턴스 매개변수에 입력합니다.
- Model Cleanup은 Revit 모델에서 뷰, 일람표, 시트, 뷰 템플릿, 필터, 링크, 가져온 항목 및 이미지를 일괄 삭제합니다. 제거할 요소를 선택하고 한 번의 클릭으로 모두 삭제할 수 있습니다.
- Revision Clouds Remover는 Autodesk Revit 모델에서 리비전 구름을 일괄 제거합니다.
- 2D & 3D Measure는 2D 및 3D 뷰에서 측정합니다(두 점 사이의 거리, 모서리 길이 또는 한 점의 좌표).
- glTF Exporter는 Autodesk Revit 모델을 glTF 파일 형식으로 빠르게 내보냅니다.
- CAD Manager는 Revit 모델에서 CAD 레이어를 표시하거나 숨기고 색상을 적용합니다.
- Project Standards는 여러 요소(예: 뷰, 시트, 뷰 템플릿, 문, 창)를 한 프로젝트에서 여러 프로젝트로 한 번에 전송합니다.
- StyleSync는 원하지 않거나 사용되지 않거나 중복된 스타일을 빠르게 정리 또는 병합합니다. 선 스타일, 선 패턴, 채우기 영역, 채우기 패턴, 치수, 문자 스타일, 재료 및 패밀리를 지원합니다.
- 더 많은 도구가 곧 제공될 예정입니다.

### 지원되는 Revit 버전
2019, 2020, 2021, 2022, 2023, 2024, 2025, 2026 및 2027.
