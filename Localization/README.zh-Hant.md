適用於 Autodesk Revit 的 DiStem 工具套件包含多個可提升工作效率的 Revit 附加元件。它可協助您管理 BIM 模型資料（擷取並對應圖元屬性和參數）、清理 Revit 模型、刪除修訂雲形線、傳遞資料、在 2D 和 3D 視圖中測量距離、取得圖元座標，以及匯出為 glTF。

### DiStem 工具套件包含
- Properties Extraction Mapping 可從模型圖元中快速擷取隱藏參數和屬性（例如位置 — X、Y、Z 座標），並將其寫入現有或新的實體共用參數。
- Model Cleanup 可從 Revit 模型中批次刪除視圖、明細表、圖紙、視圖範本、篩選器、連結、匯入物件和影像。選取要移除的圖元，只需按一下即可全部刪除。
- Revision Clouds Remover 可從 Autodesk Revit 模型中批次移除修訂雲形線。
- 2D & 3D Measure 可在 2D 和 3D 視圖中進行測量（兩點之間的距離、邊的長度或單一點的座標）。
- glTF Exporter 可將 Autodesk Revit 模型快速匯出為 glTF 檔案格式。
- CAD Manager 可在 Revit 模型中顯示、隱藏 CAD 圖層並為其加上色彩。
- Project Standards 可一次將多個圖元（例如視圖、圖紙、視圖範本、門和窗）從一個專案傳遞至多個專案。
- StyleSync 可快速清理或合併不需要、未使用和重複的樣式。支援線樣式、線型樣式、填滿區域、填滿樣式、標註、文字樣式、材質和族群。
- 更多工具即將推出。

### 支援的 Revit 版本
2019、2020、2021、2022、2023、2024、2025、2026 和 2027。
