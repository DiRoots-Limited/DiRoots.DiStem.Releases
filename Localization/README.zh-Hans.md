适用于 Autodesk Revit 的 DiStem 工具包包含多个可提高工作效率的 Revit 加载项。它可帮助您管理 BIM 模型数据（提取并映射图元属性和参数）、清理 Revit 模型、删除修订云线、传递数据、在二维和三维视图中测量距离、获取图元坐标以及导出为 glTF。

### DiStem 工具包包含
- Properties Extraction Mapping 可从模型图元中快速提取隐藏参数和属性（例如位置 — X、Y、Z 坐标），并将其写入现有或新的实例共享参数。
- Model Cleanup 可从 Revit 模型中批量删除视图、明细表、图纸、视图样板、过滤器、链接、导入对象和图像。选择要删除的图元，只需单击一次即可全部删除。
- Revision Clouds Remover 可从 Autodesk Revit 模型中批量删除修订云线。
- 2D & 3D Measure 可在二维和三维视图中进行测量（两点之间的距离、边的长度或单个点的坐标）。
- glTF Exporter 可将 Autodesk Revit 模型快速导出为 glTF 文件格式。
- CAD Manager 可在 Revit 模型中显示、隐藏 CAD 图层并为其着色。
- Project Standards 可一次将多个图元（例如视图、图纸、视图样板、门和窗）从一个项目传递到多个项目。
- StyleSync 可快速清理或合并不需要、未使用和重复的样式。支持线样式、线型图案、填充区域、填充图案、标注、文字样式、材质和族。
- 更多工具即将推出。

### 支持的 Revit 版本
2019、2020、2021、2022、2023、2024、2025、2026 和 2027。
