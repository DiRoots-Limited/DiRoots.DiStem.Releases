# Project Standards
{: .no_toc }
Project Standards transfers multiple elements, such as views, sheets, view templates, doors, and windows, from one project to other open projects.
{: .fs-6 .fw-300 }

## Core Features
{: .no_toc }
- List all the elements in the project.
- Rename elements, add prefixes or suffixes, and change names to uppercase, lowercase, or proper case.
- Transfer elements from one project to multiple target projects.

## Choose elements to transfer
{: #choose-elements-to-standards }

Open the source project and at least one target project before transferring elements.

1. In the list, select the source project containing the elements you want to transfer.

2. Select the checkboxes for the elements you want to transfer.

3. Select the target projects.

   ![DiStem Project Standards - Standards elements steps](../../../assets\images\ProjectStandard\DS-SelectElements.gif)<br />
   <sub>Note: the version on the image may not reflect the latest version of the application.</sub>

## Modify

Before transferring elements, make any required name changes.

1. Enter an element name in the first field, then choose **Next** or **All** to find matching elements.

   ![DiStem Project Standards - Find elements](../../../assets\images\ProjectStandard\DS-Find.gif)<br />
   <sub>Note: the version on the image may not reflect the latest version of the application.</sub>

2. Enter a replacement name and choose **Next** or **All**. For example, find all doors and replace their names with `DOOR`.

   ![DiStem Project Standards - replace](../../../assets\images\ProjectStandard\DS-Replace.gif)<br />
   <sub>Note: the version on the image may not reflect the latest version of the application.</sub>

3. Add a prefix or suffix to the element names.

   ![DiStem Project Standards - add prefix and suffix](../../../assets\images\ProjectStandard\DS-PrefixSuffix.gif)<br />
   <sub>Note: the version on the image may not reflect the latest version of the application.</sub>

4. Use the case options to set element names to uppercase, lowercase, or proper case.

   ![DiStem Project Standards - edit elements name](../../../assets\images\ProjectStandard\DS-Edit.gif)<br />
   <sub>Note: the version on the image may not reflect the latest version of the application.</sub>

### Reset

Click **Reset** to discard all name changes.

### Undo

Click **Undo** to reverse the last name change.

### Apply

Click **Apply** to save the name changes.

## Transfer
{: #standards }

Click **Transfer** to copy the selected elements to the target projects.

If the target project already contains an element with the same name, choose whether to overwrite it, skip it, or choose manually. Overwriting may replace the existing element and its parameter values.
{: .warning }
